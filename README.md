# coatless-quarto.github.io

Auto-built project index for [coatless-quarto](https://github.com/coatless-quarto), deployed to
[quarto.thecoatlessprofessor.com](https://quarto.thecoatlessprofessor.com/).

Source: [coatless/quarto-org-index](https://github.com/coatless/quarto-org-index).

Rebuilt daily by GitHub Actions plus on push to `main` and on
`repository_dispatch` event `refresh` (triggered by project repos on release).
